Job description

We're looking for a Senior Site Reliability Engineer to own and operate the platform our jobseekers rely on.

  • Design, build and maintain backend services in Java 17 / Spring Boot, from API and through to production.
  • Own the job-posting and application pipeline end to end, including the ads-tier translation that powers our paid placements.
  • Model and optimise data in MySQL and Redis, and lay the groundwork for the reporting layer that grows past 10M rows.
  • Build and instrument REST and event-driven APIs behind our load balancer.
  • Improve search and matching relevance in partnership with the data team.
  • Set up monitoring, alerting and tracing so problems surface before a user reports them.
  • Review code, mentor mid-level engineers, and help shape our technical standards.

Job requirement

  • 4+ years building production backend services, with at least 2 on a team that owned its own uptime.
  • Strong Java and Spring Boot; comfortable reading code you did not write.
  • Solid SQL — you can explain an index, a lock and a slow query without reaching for a search engine.
  • Experience with cloud infrastructure (AWS or GCP) and containerised deployments.
  • Vietnamese and working English — our specs and code reviews run in both.
  • Nice to have: Kafka, Elasticsearch, or experience on a recruitment or marketplace product.
