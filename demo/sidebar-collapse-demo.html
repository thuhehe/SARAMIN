What the reference layout changes, independent of which collapse option you pick

  1. One top bar, not two. The breadcrumb row under the old top bar is gone — Group / Page now sits inside the single bar next to the collapse toggle. Activity log and “View full spec” become icon cells on the right instead of buttons in a second row.
  2. The sidebar starts at the very top-left with a switcher block (logo + console name + ⇕), the same height as the top bar and divided from it by one hairline — the reference's top-left corner. It shrinks with the sidebar, so the corner is always one block.
  3. Groups stay expandable — icon + name + chevron per group, as today. Click a header to fold a group away, click again to see its pages; Expand all / Collapse all at the bottom of the panel turns the whole tree into a six-line index and back. Open/closed state is remembered per user.
  4. Search moves into the top bar with a ⌘K hint, so the sidebar is nav only.
  5. Page title + primary action stay in the content area, so the bar never competes with the page's own verb.
